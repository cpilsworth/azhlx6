# breadcrumb

Custom **breadcrumb** block. Purpose: Breadcrumb trail above the page content (Home > ... > current page).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell holding a <ul>; one <li> per crumb, linked crumbs as <a>, the current page as plain text in the last <li>.

## Supported variations

No variations.

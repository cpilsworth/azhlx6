# cta-cards

Custom **cta-cards** block. Purpose: Grid of cards: image on top, body with title, copy and a primary CTA pinned to the bottom (also image-only cards).

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: desktop picture (+ optional mobile picture), optional <h5>/<h6> pretitle, <h4> title, copy <p>/<ul>, CTA as <p><strong><a></a></strong></p>; cells in any split.

## Supported variations

| Variation | Option class |
| --- | --- |
| Three columns | `cols-3` |
| Centred body | `center` |
| Bordered | `border` |
| Plain (no tinted body) | `plain` |
| Two columns | `cols-2` |
| Flush section (no padding) | `flush` |
| Section spacing medium | `space-md` |
| Core-coloured card titles | `title-core` |

# table-bordered

Custom **table** block. Purpose: Data table with a thin border on every cell, a plain header row and bold first-column labels.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: first row is the header row (one cell per column); every other row is a data row; cells may hold paragraphs, bold text, lists and superscripts.

## Supported variations

| Variation | Option class |
| --- | --- |
| No header row | `no-header` |

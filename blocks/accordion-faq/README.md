# accordion-faq

Custom **accordion** block. Purpose: FAQ list of collapsible question/answer items with right chevrons, dividers and tinted answer panels.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: question cell (plain text or heading) and answer cell (paragraphs, lists, small footnotes).

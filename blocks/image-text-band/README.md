# image-text-band

Custom **image-text-band** block. Purpose: Image and text side by side (stacked on mobile), optionally followed by full-width text modules.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: teaser row: desktop picture (+ optional mobile picture), <h4>/<h3> title, copy paragraphs/lists, optional CTA <p><strong><a>; every other row is a full-width text module.

## Supported variations

| Variation | Option class |
| --- | --- |
| Image right | `text-image` |
| Text left-aligned | `text-left` |
| Desktop spacing medium | `space-desktop-md` |
| Desktop spacing | `space-desktop` |
| Spacing medium | `space-md` |
| Core-coloured title | `title-core` |
| Spacing | `space` |
| Spacing before trailing text | `text-space` |

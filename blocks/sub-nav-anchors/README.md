# sub-nav-anchors

Custom **sub-nav** block. Purpose: In-page anchor navigation bar with vertical separators, horizontally scrollable with arrow buttons on overflow; highlights the section in view.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row, one cell holding a <ul>; one <li><a href="#anchor">label</a></li> per in-page target (target ids must exist on the page).

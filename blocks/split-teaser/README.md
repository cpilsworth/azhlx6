# split-teaser

Custom **split-teaser** block. Purpose: Copy with primary CTA on the left, image on the right (stacked image-first on mobile).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: desktop picture (+ optional mobile picture, optionally linked), optional heading, copy paragraphs/lists, CTA as <p><strong><a></a></strong></p>; rows/cells in any split.

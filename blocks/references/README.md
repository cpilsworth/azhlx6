# references

Custom **references** block. Purpose: Small-type references footer: abbreviation notes, bold label and numbered citation list.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: any number of rows/cells: notes as <p>, a fully bold <p> label, citations as <ol>; each further row opens a new spaced text module.
